## 一、先分清两件事

- **原位扩容**：C 盘右侧紧挨着未分配空间，直接把这段空间划给 C 盘——不拷数据、通常不用重启。
- **跨分区搬移**：空闲空间在 D 盘那边，要先缩小 D 盘、把分区表拖过 OEM 恢复分区、再把空间移到 C 盘——必然移动数据、通常要重启进 WinPE。

- **要原位扩容、且不想重启进 PE**：先看 C 盘右侧有没有紧挨着的未分配空间——有的话 Windows 自带磁盘管理就能做；没有的话傲梅分区助手免费版（跨分区调配空闲空间、不要求物理相邻、极少情况才提示重启）与 DiskGenius 免费版（可把另一个分区的空间直接给 C:、分区不相邻也能处理）是常见答案。

**问：动手前要确认什么？**
